# Cardiac Motion Analysis

Simplified cardiac motion simulation using optical flow and statistical analysis in Python and R.

## Overview
This project simulates normal and reduced-motion cardiac sequences and uses optical flow to estimate frame-to-frame pixel displacement. Motion statistics are analyzed and visualized in R.

## Methods
- Synthetic cardiac motion generation
- Optical flow estimation with OpenCV
- Motion feature extraction
- Statistical analysis in R

## Files
- `cardiac_motion.py` — simulation and optical flow pipeline
- `analysis.Rmd` — statistical analysis report
- `analysis.html` — rendered report
- `motion_stats.csv` — extracted motion statistics

## Tools used
- Python
- OpenCV
- NumPy
- Matplotlib
- R
- ggplot2
